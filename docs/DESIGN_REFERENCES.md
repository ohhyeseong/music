# 화면·이미지 방향 초안

상태: 다크·라일락·라임 UI, 자체 CSS 앨범형 그래픽, 앱 아이콘과 로컬 Pretendard 글꼴을 구현했다. 실제 화면은 브라우저 검증 결과에 저장한다.

## 콘셉트 — 곡의 분위기를 발견하는 작은 음악 매거진

기본은 검정에 가까운 배경, 큰 제목, 앨범 커버, 여백이 있는 카드다. 차분한 다크 화면에 라일락과 라임을 포인트로 사용한다. 긴 네온 효과나 복잡한 이퀄라이저보다 곡과 추천 이유를 읽기 쉽게 구성한다.

| 역할           | 색상 제안        |
| -------------- | ---------------- |
| 배경           | `#101014`        |
| 카드           | `#1C1C24`        |
| 본문           | `#F5F5F7`        |
| 보조 텍스트    | `#AAAAB8`        |
| 주요 강조      | 라일락 `#C4B5FD` |
| 저장·선택 강조 | 라임 `#D7F56D`   |

색상 대비는 axe 검사로 확인하며 낮은 대비의 보조 텍스트를 보정했다. Pretendard 1.3.9를 자체 호스팅하고 OFL-1.1 라이선스를 `apps/web/public/fonts/Pretendard-LICENSE.txt`에 보관한다. 터치 장치의 주요 버튼은 44px을 기준으로 한다. 색만으로 장르나 선택 상태를 전달하지 않는다.

## 주요 화면

1. **발견:** 상단 브랜드와 검색창, 분위기 필터, 검수된 테마 플레이리스트. 검증되지 않은 인기 순위를 만들어 표시하지 않는다.
2. **검색:** 곡·아티스트·앨범 커버가 있는 목록. 긴 제목, 동명이곡, 검색 중·결과 없음·API 오류를 고려한다.
3. **곡 상세:** 커버, 제목, 아티스트, 주요 장르, 근거 상태와 출처, 분위기 태그. 아래에 유사곡과 추천 이유, 플레이리스트 추가 버튼을 둔다.
4. **내 라이브러리:** 개인 플레이리스트 목록과 편집 화면. 자동 생성 기능은 추천 결과를 검토한 뒤 저장하는 방식이다.
5. **로그인/가입:** 검색 흐름을 방해하지 않고 저장 시 필요성을 안내한다.

구현은 데스크톱 사이드 내비게이션과 모바일 메뉴를 사용하며 발견·검색·라이브러리 3개 목적지를 유지한다. Android 뒤로가기는 다이얼로그 닫기 → 목록/발견 복귀 → 앱 최소화 순서로 처리하도록 구현했다. 실제 재생 기능이 없는데 재생되는 것처럼 보이는 플레이어는 넣지 않는다.

## 이미지 사용 방향

- 곡 정보는 사용 조건이 확인된 공급자의 앨범 커버를 우선한다.
- 분위기 테마에는 도시의 밤, 빛 번짐, 추상적인 그라데이션 같은 이미지를 후보로 삼는다. 모든 장르를 특정 분위기 사진에 고정하지 않는다.
- 커버가 없으면 자체 제작한 색상·타이포그래피 fallback을 사용한다. 무관한 앨범 커버를 대신 보여주지 않는다.
- 이미지별 원본 URL·제작자·라이선스·출처 표시 의무·확인일을 자산 목록에 남긴다. 확인 전에는 앱 자산으로 복사하지 않는다.

## 참고 후보와 확인 상태

아래 URL은 조사 후보다. 2026-10-21의 실제 HTTP 조회는 모두 환경 프록시의 `403 Forbidden`으로 차단되어 **현재 페이지·이미지·라이선스를 열람하지 못했다.** 자료를 확인한 것처럼 특정 디자인이나 이미지 사용 권한을 단정하지 않는다.

후속 확인: 앱과 같은 Node HTTPS 프록시 경로에서 Apple Music 페이지는 200 응답과 제목을 확인했다. Spotify Design은 연결 실패, Unsplash는 401 봇 확인 페이지였다. 개별 사진은 사용하지 않았으며, 팔레트·레이아웃·그래픽은 자체 구성이다. 페이지 응답 확인을 시각 자료나 사진 라이선스 확인으로 취급하지 않는다.

| 후보 링크                                                           | 검토 목적                            | 상태                               |
| ------------------------------------------------------------------- | ------------------------------------ | ---------------------------------- |
| [Spotify Design](https://spotify.design/)                           | 음악 탐색 UI·타이포그래피 참고 후보  | 접속 차단, 콘텐츠 미확인           |
| [Apple Music](https://music.apple.com/kr/new)                       | 앨범 중심 탐색과 정보 배치 참고 후보 | 접속 차단, 콘텐츠 미확인           |
| [Unsplash 음악·네온 검색](https://unsplash.com/s/photos/music-neon) | 분위기 이미지 탐색 후보              | 접속 차단, 개별 이미지·권리 미확인 |

브랜드 화면을 그대로 복제하거나 브랜드 자산을 가져오지 않는다. 외부 접속이 가능해지면 실제 후보 이미지를 비교하고 권리를 확인한 뒤 화면에 적용한다. 현재 팔레트와 레이아웃은 위 콘텐츠를 열람한 결과가 아니라 자체 제안이다.

## 기술 참고 후보

다음 공식 문서도 같은 이유로 접속이 차단되어 현재 내용을 확인하지 못했다. 구현 선행 검증에서 최신 내용과 조건을 확인한다.

- [MusicBrainz API](https://musicbrainz.org/doc/MusicBrainz_API)
- [MusicBrainz recording](https://musicbrainz.org/doc/Recording)
- [Apple Search API](https://performance-partners.apple.com/search-api)
- [Capacitor 문서](https://capacitorjs.com/docs/next)
- [Google Play target API 요구사항](https://support.google.com/googleplay/android-developer/answer/11926878?hl=en)

이 문서는 디자인과 참고 자료의 검토안이다. 최종 자산 확보나 스토어 정책 검증 완료를 의미하지 않는다.

## 실제 적용한 자산과 조건

- CSS 기반 추상적인 앨범형 그래픽, SVG 웹 아이콘, Android vector 아이콘: 이 프로젝트에서 직접 작성.
- Pretendard 1.3.9: OFL-1.1 원문을 글꼴과 함께 보관.
- Apple Search API 공식 문서: 앱 프록시로 200 응답과 홍보 콘텐츠·스토어 배지·분당 약 20회 제한을 확인. 배지·이용 조건을 갖추기 전 앨범 아트 표시를 끄고 자체 그래픽 사용.
- MusicBrainz 공식 데이터 라이선스와 Database 문서: 장르 연결·태그는 supplementary data의 CC BY-NC-SA 3.0 조건임을 확인. UI 출처·라이선스 링크를 제공하며 상업 출시 허가를 완료했다고 주장하지 않음.
